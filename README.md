# Tic-Tac-Toe

A simple Tic-Tac-Toe game made using HTML, CSS and JavaScript.

## Features

* Two-player game
* Player X and Player O turns
* Checks for a winner automatically
* New Game button to start a new game
* Reset Game button to reset the current game
* Simple and clean interface

## Technologies Used

* HTML
* CSS
* JavaScript

## How to Play

1. Player X starts the game.
2. Players take turns clicking on an empty box.
3. The player who gets three of the same symbols in a row, column or diagonal wins.
4. If all the boxes are filled and nobody wins, the game is a draw.
5. Click New Game to start another game or Reset Game to reset the board.
